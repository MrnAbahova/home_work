# Виджет личного кабинета клиента
## Описание
Проект "Виджет личного кабинета клиента" - это виджет, который показывает 
несколько последних успешных банковских операций клиента.
## Установка:
1. Клонируйте репозиторий
 ```
   git clone https://github.com/MrnAbahova/home_work/pulls
 ```

2. Установите зависимости
```
pip install -r requirements.txt
```

3. Установите библиотеки
```
   pip install requests
```
## Тестирование
1. Используемые инструменты: Для тестирования используется библиотека "pytest"
### Установка через Poetry:
poetry add --group dev pytest
2. Запуск тестов: Запустить тесты можно используя команду "pytest" в корневой папке проекта
3. Покрытие тестами: Код покрыт тестами более чем на 80%, есть отчет в формате HTML в папке htmlcov
